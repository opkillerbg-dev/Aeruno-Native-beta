## Investigated first
- Project: Kotlin + Compose, Haze 1.7.2 already in (N03), minSdk 31, owner phone Android 16.
- N03 card blur was a backdrop blur clipped to a rounded card with uniform radius. Not reused as is.
- Options checked against Haze 1.7.2 docs (VERIFIED, web): (1) `HazeProgressive.verticalGradient(startIntensity, endIntensity, easing)` inside `hazeEffect { progressive = ... }`: real variable blur radius along a gradient; (2) `mask = Brush` on the effect: only fades opacity of one uniform blur (docs: faster, "not as refined"); (3) hand-stacked blur layers: more code, visible banding, rejected. Docs warn progressive is slow only on Android 12L/13 (SDK 32); the owner's phone is Android 16.
- Chosen: **(1) progressive**, no new dependency. `preferPerformance` left false (quality).
