## Haze evaluation (decision log)
- Chosen: **1.7.2**, last stable 1.x. Rejected: 2.0.x / 2.1.0 (newest, 2026-11-02): changelog says Kotlin 2.4.x and Compose 1.12.x, newer than this project (Kotlin 2.3.0, BOM 2026.05.00), plus a new API (`haze-blur` artifact). Not worth a toolchain upgrade inside a prototype card.
- Complexity: one dependency, one file. No stop condition hit. If the build fails on Haze, I stop and report; no fake blur.

## Evidence
- VERIFIED (web, Haze official changelog, 2026-11-20): version 1.7.2 exists (2026-02-10); 1.7.0 built with Kotlin 2.2.20 and Jetpack Compose 1.9.4 and called last of 1.x; 2.x requirements as above; the lines about Android 12+ blur are from Haze docs for 1.6+.
- VERIFIED (sandbox): bracket balance of both new Kotlin files.
- NOT verified: that Haze 1.7.2 resolves and compiles with Kotlin 2.3.0 / BOM 2026.05.00 / AGP 8.13.2. That is an inference from "newer compiler reads older metadata", not a test.
